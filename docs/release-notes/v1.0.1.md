### What changed

**The repository shows its current build and distribution information.** The
README adds badges for CI on `main`, the latest release, the required Go
version, the license and standard-library-only dependencies, plus direct links
to installation, the demo, design and security documentation. The status and
version badges read their values from GitHub rather than storing a result that
will go stale.

**An optional Linux container joins the standalone binaries.** The release
workflow packages the existing `linux/amd64` and `linux/arm64` binaries in a
minimal image at `ghcr.io/jegoba90/ganimedes-project`, links it to this
repository's Packages section, and attests the published image digest. Docker
is an additional distribution format; the standalone binary still needs no
container runtime or account.

Manual workflow runs build and check the container without publishing, even
when the selected ref is an existing tag. Publication requires a tag push.

The image contains `/ganimedes`, with no shell, MCP server or server runtime.
It can verify mounted logs or supply the binary to an image that already
contains a server. `run` and `scan` need that server inside the same container;
ordinary port publishing does not expose the loopback-only approval page.
The [container guide](https://github.com/Jegoba90/Ganimedes-Project/blob/main/docs/CONTAINERS.md)
documents those limits, file permissions and verification by digest. Image
provenance proves origin, not safety.

### How it was found

The repository's README had no badges and its Packages sidebar was empty.
The existing executable assets live under Releases, which does not populate
Packages. The container is a separate artifact for that channel and reuses the
release binaries rather than introducing a second compilation path.

### Why a patch

No Go source or gateway behavior changes. The CLI, exit codes, configuration,
audit format and forwarded protocol bytes keep their existing meaning. This
release adds repository presentation and an optional distribution artifact.
